## Ingestion requirements

1. Read the complete current character fidelity handoff, source index and source manifest.
2. Retrieve each relevant source through its exact RAW URL where possible. Read the complete file, not only the opening lines or a search excerpt.
3. If RAW is blocked, use its matching GitHub browser page. Do not claim a successful read merely because a link opened or a directory listing appeared.
4. Read files in manageable batches. Large files may require multiple line-range reads if the environment truncates them.
5. Keep every original file independent. Dated/revision variants are separate artifacts.
6. Preserve source authority and state distinctions. Do not silently reconcile conflicts.
7. Record exact files fully read, partially read, inaccessible, or truncated.
8. The handoff record is a review/navigation record, not a replacement for complete character owners. The Chris possum concept remains a selected supplement awaiting formal incorporation.
9. Remain in WORK mode unless Kaze explicitly authorizes PLAY. No fictional time advancement or scene execution is authorized by source ingestion.
